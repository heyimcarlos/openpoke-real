Lesson 1

Execution glossary

The smallest vocabulary needed to reason about OpenPoke's durable execution design.

Thread

The durable, ordered conversation identity for one tenant, actor, and channel.

Message

A durable input or output record. Ingress order and model-context order are separate.

Agent Run

One bounded, disposable interaction turn over an exact Thread cutoff. It is not a resident agent process.

Conversation-agent worker pool

Replicas of server.orchestrator_worker polling and claiming Agent Runs.

Execution task

Independent durable work delegated by the conversation agent or created as a Workflow Step.

Execution worker pool

Bounded worker slots that claim execution tasks and invoke a fixed executor.

Lease

Temporary permission for one worker and generation to commit a result before expiry.

Fence

A completion check on worker identity, lease generation, status, and expiry that rejects stale work.

Queue

A distributor of work already declared runnable. Today queued PostgreSQL rows provide this role.

Workflow Kernel

Deterministic authority that decides which Step is runnable and what transition follows completion.

Workflow Definition

Immutable, versioned, server-owned structure. A model may select it but cannot rewrite its graph.

Result continuation

An execution result appended as new Thread ingress, causing a later conversation Agent Run.

Agents SDK Runner

The temporary reasoning and tool loop inside one claimed execution task.

RabbitMQ wake-up

A future delivery hint. It does not own state and cannot grant execution authority.
